Data & privacy

This prototype saves data in this browser on this device. It does not automatically sync across devices or browsers. Export a backup regularly, especially before clearing browser data.

Important: browser storage can be lost if you clear site data, use private/incognito mode, or uninstall/clear browser data. Export backups to protect your records. A future version can add secure cloud sync and login.

How to use this system

  1. Write your vision and the 90-day focus.
  2. Add 1–3 measurable goals for the current stage.
  3. Break them into weekly outcomes and daily tasks.
  4. Log real results and experiments, including failures.
  5. Run a weekly review and choose next week's priority.
  6. Export a backup weekly.

Danger zone

This permanently clears records saved in this browser. Export a backup first.
